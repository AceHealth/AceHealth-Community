# Contributing to the Ace community

You can help by reporting bugs, describing feature ideas, answering questions, and sharing constructive feedback.

1. Search [issues](https://github.com/AceHealth/AceHealth-Community/issues) and [discussions](https://github.com/AceHealth/AceHealth-Community/discussions) first.
2. Use the bug or feature form for a new issue. Keep one problem or idea per issue.
3. Include enough detail to understand the problem. For bugs, include your app version, device, operating system, and steps to reproduce.
4. Ask usage questions in Q&A. Mark a reply as the answer when it resolves your question.
5. Remove private information before submitting. Never include health exports, credentials, or account identifiers.

The team reviews new issues, asks for missing details, and updates labels as work progresses. There is no guaranteed response time. A closed request may be a duplicate, out of scope, or something we cannot reproduce; maintainers should explain the reason.

Documentation corrections are welcome as pull requests. Application code changes belong in the application repository, not here. Follow the [community guidelines](CODE_OF_CONDUCT.md).
