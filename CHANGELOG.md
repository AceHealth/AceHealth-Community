# Release notes

[GitHub Releases](https://github.com/AceHealth/AceHealth-Community/releases) is the canonical home for Ace release notes.

No app release notes have been published in this community repository yet. Repository setup does not represent an app release.

Each release will describe what is new, what improved, what was fixed, and any known issues. Availability and minimum supported versions will be stated when relevant.

Maintainers: use the [release note template](docs/RELEASE_TEMPLATE.md). Do not duplicate release entries in this file.
