# Reporting a security vulnerability

Please do not disclose vulnerabilities in public issues or discussions.

Use [Report a vulnerability](https://github.com/AceHealth/AceHealth-Community/security/advisories/new) to send a private report to this repository's maintainers. Include the affected Ace version, a description of the impact, and steps to reproduce using test data.

Do not include real users' health information, passwords, or access tokens. Avoid accessing anyone else's data while investigating.

This reporting channel covers Ace application security as well as this community repository. Ordinary bugs belong in the bug report form. We do not promise a response or resolution deadline.
