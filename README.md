## Getting started

Search existing issues and discussions before posting. If someone has already shared your idea, add a 👍 reaction and explain your use case in a comment. A GitHub account is needed to post, comment, or react; anyone can read this repository.

Use **Watch → Custom → Releases** to follow release notes, or watch Discussions and Issues for broader updates.

## Your privacy

Everything posted here is public. Remove names, email addresses, health records, account details, and other personal information from screenshots and reports. Never post passwords, access tokens, or raw health exports. Community conversations are about using Ace; they are not a place for medical diagnosis or treatment advice.

For a security vulnerability, use [private vulnerability reporting](https://github.com/AceHealth/AceHealth-Community/security/advisories/new), not a public issue. Account-specific problems should use the private support option available in Ace.

## How this space works

Bugs and feature requests live in Issues. Questions live in Q&A, where helpful replies can be marked as answers. The Ace team posts announcements and release notes. Roadmap labels describe current intent, and may change as we learn.

This repository hosts community content; the Ace application source code is maintained separately. See [contributing](CONTRIBUTING.md) and our [community guidelines](CODE_OF_CONDUCT.md).
